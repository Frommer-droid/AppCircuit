# История изменений

## 0.6.0 — 2026-09-26

- Добавлены сессии с упорядоченными действиями: запуск и остановка программ,
  открытие файлов и паузы между шагами.
- Сессии можно экспортировать в JSON по галочкам и импортировать без удаления
  остальных; совпадение имён заменяет соответствующую сессию.
- Для подсвеченной сессии можно создать отдельный EXE, который выполняет
  сохранённые шаги без запуска окна AppCircuit и без установленного Python.
- Интерфейс получил автоматический масштаб с ручной поправкой, сохранение
  геометрии, более широкое окно при первом запуске и видимые стрелки списков.
- Сборка PyInstaller проверяет происхождение DLL и использует согласованный
  комплект MSVC runtime для PySide6.
- Собственный код AppCircuit теперь распространяется по лицензии MIT;
  лицензии Qt/PySide6 и других компонентов остаются самостоятельными.

## 0.5.0 — 2026-07-18

- Portable-копии программ с одинаковым именем процесса теперь различаются по
  полному пути к исполняемому файлу и запускаются независимо.
- Остановка выполняется адресно по PID выбранного пути вместе с дочерними
  процессами и не затрагивает одноимённые приложения из других каталогов.
- WinAPI-перечисление процессов заменило проверку только по имени и возвращает
  соответствие нормализованных путей фактическим PID.
- Новые записи получают отображаемое имя из родительской папки `.exe`, а старые
  дублирующиеся имена автоматически разделяются по каталогам.
- Добавлены регрессионные тесты разных portable-копий, точечной остановки,
  нескольких PID одного приложения и миграции отображаемых имён.

## 0.4.0 — 2026-07-18

- Диалог добавления приложений остаётся открытым после выбора файлов и позволяет
  последовательно добавлять `.exe` из разных каталогов до закрытия крестиком.
- В боковой панели диалога появились рабочий стол, системный пункт «Мой
  компьютер», подключённые диски, домашняя папка и пять последних каталогов.
- Последние каталоги сохраняются в `settings.json`, поднимаются при повторном
  использовании и очищаются от дублей и недоступных путей.
- Таблица выбора файлов получила отдельный столбец даты создания.
- Кнопка подтверждения «Добавить» получила нормальный прямоугольный размер,
  внутренние отступы и согласованные состояния интерфейса.
- Добавлены автоматические тесты постоянного диалога, боковой панели, истории
  каталогов, дополнительного столбца и оформления кнопки.

## 0.3.0 — 2026-07-18

- Приложение полностью переименовано в AppCircuit с обновлением исполняемого
  файла, установщика, Windows-идентификаторов и сборочной инфраструктуры.
- Список приложений и геометрия автоматически переносятся из соседней папки
  прежней установки; portable-обновление сохраняет `settings.json`.
- Перед запуском отмеченных программ AppCircuit проверяет активные процессы и
  не создаёт второй экземпляр уже работающего приложения.
- Кнопка остановки получила отдельный красный фон и состояния наведения,
  нажатия и блокировки.
- Из репозитория удалены исходник и exe прежней реализации, а также
  неиспользуемые дубликаты иконки.

## 0.2.1 — 2026-07-18

- Удалены предустановленные приложения: новая установка открывается с пустым списком.
- Начальная и минимальная ширина окна теперь рассчитывается по фактической ширине панели кнопок.
- Сохранённые список и геометрия окна существующих пользователей продолжают использоваться.

## 0.2.0 — 2026-07-18

- Добавлена воспроизводимая `onedir`-сборка через PyInstaller.
- Добавлены GUI-сборщик, post-build manifest, Windows-установщик Inno Setup и portable-перенос.
- Добавлен комплект уведомлений о сторонних компонентах и лицензиях Qt/PySide6.
- Версия проекта теперь читается из единственного файла `VERSION`.
- Добавлены автоматические проверки build/release-конфигурации.
- Pytest обновлён до безопасной ветки 9.x по результатам OSV-аудита.

## 0.1.0 — 2026-07-18

- AHK-приложение перенесено на Python 3.12 и PySide6.
- Добавлен редактируемый пользовательский список программ.
- Добавлены запуск и остановка приложений с установленными галочками.
- Добавлено сохранение списка и геометрии окна.
- Добавлены русская локализация, тёмная тема, тесты и Ruff.
